ℹ️ About SimonPeter AI

AI-Powered Personal Assistant

SimonPeter AI is a personal assistant powered by NVIDIA NIM AI integration for accurate, intelligent conversations across many domains.

Capabilities:
• 💬 Natural language chat with AI backend — asks and answers any question
• 💻 Programming help — Python, JavaScript, Java, C++, and more
• 🔢 Math — step-by-step solutions for any math problem
• 🔬 Science, history, geography — accurate factual answers
• 🔐 Cybersecurity — detailed technical knowledge
• 🌤 Live weather data
• 📝 Notes with localStorage
• ⏰ Reminders with notifications
• 🧮 Built-in calculator
• 🎤 Voice input & responses (Web Speech API)

Built with: HTML, CSS, JavaScript, NVIDIA NIM AI backend — no frameworks, no dependencies.
